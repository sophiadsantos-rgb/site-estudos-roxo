# StudySpace ✦

## Tema
Site educativo de estudos e organização escolar.

## Objetivo
Criar um espaço para apresentar matérias, dicas de organização e planejamento dos estudos.

## Páginas
- index.html
- sobre.html
- informacoes.html
- contato.html

## Tecnologias
- HTML5
- CSS3
- Bootstrap 5.3 via CDN
- Google Fonts (Poppins)
- Git e GitHub
- GitHub Pages

## Componentes Bootstrap
- Navbar
- Cards
- Buttons
- Alert
- Badges
- Table
- Forms

## Responsividade
O projeto utiliza o Grid System do Bootstrap com `container`, `row` e `col-*`.
